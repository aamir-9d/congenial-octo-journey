# E2E Apps site

Read the newest file in `changelog/` before starting work, and `NOTES.md` before
changing anything visual.

**Before ending any session that changed something** (code, DNS, Worker, content,
settings) or made a decision:

1. Record it in `changelog/YYYY-MM-DD.md` and add the row to
   `changelog/README.md`. Carry unfinished Open items forward.
2. Update the project memory with what the repo does not record.

This repository is public: no personal emails, account names, keys, client names
or confidential material in the changelog.
