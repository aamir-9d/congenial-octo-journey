## Lighthouse failure on the visitor-counting pull request
- The Lighthouse check failed. The job log needs a sign-in, so the cause was
  found by running Lighthouse locally: the beacon, as a plain deferred tag, ran
  about 80 ms of script during page load, and on any host other than the live
  one its request was refused and logged a console error.
- Fix: the beacon now loads after the load event at idle, like Tag Manager,
  and only on the live host.
- Verified: 158 tests pass. In a browser on the dev server the beacon does not
  load; injected the same way by hand it reads its token and sends its report.
- Not verified: the Lighthouse check itself (it reruns on the pull request),
  and a real visit being counted on the live site after merge.
- Pull requests 18 and 19 were merged before this fix, so it is on its own
  branch, `beacon-idle`.
