Serve the repo root over HTTP and open this file from that server, not from file:// — the export needs to fetch React from unpkg, and file:// blocks it. From the repo root: npx serve -l 8080 . then open http://localhost:8080/scripts/compare.html. Build the port first (npm run build). The export is the original E2E Apps Homepage.dc.html; if it renders blank, check the console — it means unpkg was unreachable.
