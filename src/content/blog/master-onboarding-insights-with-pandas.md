## Data aggregation and cleanup in Pandas

This approach combines unique values across multiple columns while grouping data by `deviceID`, ensuring no duplicates or NaN values get in the way. By applying a custom `join_unique_values()` function, we can simplify data cleanup and aggregation in one step.

```python
def join_unique_values(series):
    return ', '.join(series.dropna().astype(str).unique())

combined_interests = df.groupby('deviceID').agg({
    'country_code': join_unique_values,
    'triggerfrom': join_unique_values,
    'status': join_unique_values,
    'transaction': join_unique_values
}).reset_index()
```

## Filtering and cleaning with replace and contains

This code replaces any instance of `'done, error in purchase'` in the status column with `'done'` to standardize the status values. It then filters the data to include only rows where status contains the word "done", regardless of case, ensuring a clean dataset focused on completed transactions.

```python
data['status'] = data['status'].replace('done, error in purchase', 'done')

filtered_data = data[data['status'].str.contains('done', case=False, na=False)]
```

## Country-based aggregation and conversion rate calculation

This approach groups data by `country_code` to analyze transaction statuses, providing insights into success and error rates. Using `agg`, it calculates the total count of records per country, counts rows with "done" and "error in purchase" statuses, and calculates conversion rates for each status:

- **total_count** — total records for each `country_code`.
- **done_count** — rows where status is "done".
- **error_count** — rows where status is "error in purchase".

The counting of done and error statuses is done using lambda functions, which check for specific conditions and sum up the `True` values. Finally, conversion rates are calculated as percentages, showing the success (done) and error (error in purchase) rates per country.

```python
summary = df_filtered.groupby('country_code').agg(
    total_count=('status', 'count'),
    done_count=('status', lambda x: (x == 'done').sum()),
    error_count=('status', lambda x: (x == 'error in purchase').sum())
).reset_index()

summary['cvr_done'] = summary['done_count'] / summary['total_count'] * 100
summary['cvr_error'] = summary['error_count'] / summary['total_count'] * 100
```

## Mapping country codes using a dictionary

This code snippet defines a mapping between country names and their corresponding country codes using a dictionary called `country_code_map`. It then creates a `reverse_country_code_map` that allows for easy lookup of country names based on country codes.

1. **Country code mapping:** the `country_code_map` dictionary associates each country with its ISO code (e.g. 'United States' → 'US').
2. **Reverse dictionary creation:** the `reverse_country_code_map` is generated by swapping keys and values from the original dictionary, enabling lookups from code to country name.
3. **Mapping in DataFrame:** the `map` function is applied to the `countryCode` column in `final_df`, replacing each country code with its corresponding country name from the `reverse_country_code_map`. This ensures that the DataFrame contains user-friendly country names rather than codes, enhancing readability and analysis.

```python
country_code_map = {
```

## Random selection function for data handling

The following code defines a function called `pick_random_category` that randomly selects one category from a list of categories in a given row.

1. **NaN check:** the function first checks if the row value is NaN (not a number). If it is, the function returns NaN to maintain data integrity.
2. **Splitting categories:** if the row contains a string of categories, it splits this string into a list using `', '` as the delimiter.
3. **Random selection:** the function then uses `random.choice()` to randomly pick one category from the list. This approach is useful when dealing with data entries that may belong to multiple categories, ensuring that a single representative category is selected for further analysis or processing.

```python
def pick_random_category(row):
    if pd.isna(row):
        return row
    categories = row.split(', ')
    return random.choice(categories)
```
