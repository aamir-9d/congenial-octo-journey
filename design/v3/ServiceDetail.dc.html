Common attribution mistakes, and the fix.

Each card names the mistake, how it shows up in your reports, and what puts it right.

Mistake 01

The SDK starts before consent is answered

How it shows up

iOS installs arrive without an advertising ID

The fix

Set the launch order and wait time, then test each answer

Mistake 02

The SKAN schema measures only revenue

How it shows up

Trial apps send empty or low values

The fix

Map early signals that happen inside the first window

Mistake 03

Ad platforms receive the wrong events

How it shows up

Campaigns optimise for a weak signal

The fix

Map the events that match the campaign goal

Mistake 04

Send both fields in the right format

Mistake 05

Document a reason for every difference

Scope

When you need it, what it checks, what you get

When do you need an attribution audit?

Google Ads, Meta, the MMP and RevenueCat report different revenue. Organic installs rise when paid spend rises. Trials appear in the MMP but renewals do not. iOS campaigns have little or no conversion data. Nobody knows why a setting was chosen.

What does an attribution audit check?

SDK version, start-up and user identity Attribution windows, view-through and reattribution SKAN and AdAttributionKit Each ad partner connection and postback Event names, triggers and values Trials, purchases, renewals and refunds Web-to-app links and deep links Privacy and consent settings GA4, Firebase and cost data
